# ⚓ Batalha dos Pronomes Online

Jogo educativo multiplayer de Batalha Naval com perguntas sobre pronomes da Língua Portuguesa, desenvolvido com Node.js, Express e Socket.IO.

## 🚀 Como Rodar Localmente

1. Instale o [Node.js](https://nodejs.org/) (versão 18+ recomendada).
2. Abra o terminal nesta pasta e execute:
   ```bash
   npm install
   ```
3. Inicie o servidor:
   ```bash
   npm start
   ```
4. Acesse no navegador: `http://localhost:3000`

## 🌐 Deploy no Render

1. Suba esta pasta para um repositório no seu GitHub.
2. No painel do [Render](https://render.com), clique em **New +** -> **Web Service**.
3. Conecte o repositório do GitHub.
4. Preencha as configurações:
   - **Environment / Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. Clique em **Create Web Service**.
